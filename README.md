# Mundo de Brincar — APKs

Canal público de versões Android do jogo educativo Mundo de Brincar.

Baixe os APKs na seção Releases. A partir da versão 0.4.1, o jogo verifica a última release estável ao iniciar e oferece o download na área dos responsáveis. As brincadeiras continuam funcionando offline.

Este repositório contém somente arquivos de distribuição e informações das versões. Não contém código-fonte do jogo, chaves de assinatura ou modelos de voz.
